# macOS 验收

当前状态：原生源码实现已加入仓库；Windows 环境无法执行 AppKit 编译或真实 Codex 交互。请先确认 GitHub Actions 中 `macos-14` 的编译及自测任务通过，再进行以下实机验收。CI 自测不会打开窗口或授予权限。

## 环境

- macOS 12+，当前版本 Codex 桌面版。
- Node.js 18+、可运行 `plugin` 命令的 Codex CLI。
- Xcode Command Line Tools，用于本机编译 Swift/AppKit 客户端。
- 分别记录 Intel / Apple Silicon、系统版本、Codex 版本与显示器缩放设置。

## 检查项目

1. 运行 `bash start-macos.sh`：编译成功，菜单栏出现 CAT；没有辅助功能授权时不要在随机位置显示猫咪。
2. 在系统设置授予 Codex Usage Cat 辅助功能权限：回到 Codex 输入框，猫咪自动出现。
3. 从输入框左向右行走，在素材停步帧原地播放，到边界停下后折返。
4. 停步发射左右错峰气泡：从猫咪头顶零尺寸长大，上浮、爆开；猫咪继续走动时气泡不得横移。
5. 右键菜单：查看详情在头顶展开，不打开浏览器；关闭动效、切换中文/英文、拖动和恢复轨道有效。
6. 在输入框持续打字，猫咪不得抢占键盘焦点或发送文本。
7. 移动、缩放 Codex 窗口，输入框增高后轨道更新；找不到输入框时隐藏。
8. 切到 Finder / 其他应用、最小化 Codex 后隐藏；返回 Codex 时恢复；退出 Codex 后应用和数据泵结束。
9. 让 Codex 跨越内置 Retina 屏和外置屏；检查输入框位置、气泡裁剪和比例。当前输入框坐标使用主屏基准进行全局转换，需要重点验证上下排列的显示器。
10. 对照 Codex 额度确认 5 小时 / 周百分比；今日建议预算为 0 时，气泡仍显示真实额度；日志读取失败时保留上次数据。

## 日志与更新

- `~/.codex/usage-coach/mac-build.log`：Swift 编译和本机签名日志。
- `~/.codex/usage-coach/coach.log`：用量同步错误。
- `CODEX_HOME` 被设置时，使用对应主目录下的 `usage-coach`。
- 更新 Swift 后重新构建可能需要在系统设置中重新授予辅助功能权限。本机生成的应用使用临时签名，尚非 Apple 公证安装包。

发现错误时记录上述版本信息、是否已授权以及日志；不要上传 `auth.json`、完整会话日志或令牌。
